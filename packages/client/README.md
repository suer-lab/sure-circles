# Sure Circles client SDK

`@sure-circles/client` is the TypeScript SDK for the Sure Circles contract on Stellar/Soroban. It covers
three jobs: building identities and Merkle trees, generating Groth16 membership proofs locally, and
calling the contract (create, fund, claim, read).

> [!NOTE]
> The package is consumed as built output from `dist/`. Consumers such as the `app/` workspace build it first
> with `npm run build --workspace=packages/client`.

The recommended entry point is **`SureCirclesSDK`**. It binds a network, a signer and a retry policy once, so
callers do not thread a raw contract client through their code (see `docs/adr/003-client-boundary.md`). The
free functions it delegates to remain available as the low-level layer.

## 1. Connecting

```ts
import { SureCirclesSDK } from "@sure-circles/client";
import { Keypair } from "@stellar/stellar-sdk";

const sdk = await SureCirclesSDK.connect(
  {
    contractId: "C...", // the deployed Sure Circles contract
    rpcUrl: "https://soroban-testnet.stellar.org",
    networkPassphrase: "Test SDF Network ; September 2015",
  },
  Keypair.random(),
  { retryPolicy: { maxRetries: 3, baseDelayMs: 500 } },
);
```

## 2. Creating a circle

```ts
const { result: circleId, hash } = await sdk.createCircle({
  admin: sdk.publicKey,
  token: "C...", // token contract used for contributions
  root: treeRoot,
  contribution: 10_000_000n,
  size: 5,
  vk, // verification key in contract format
  feeBps: 0,
  feeRecipient: sdk.publicKey,
});
```

## 3. Funding and claiming

```ts
await sdk.fund({ circleId, from: memberPublicKey });

const { hash: claimHash } = await sdk.claim({
  circleId,
  recipient: freshRecipient,
  nullifierHash,
  externalNullifier,
  proof,
});
```

## 4. Generating a proof

Proving runs locally and needs only the free functions, not a connected SDK. The circuit WASM and proving key
are supplied by the caller (see `configureArtifacts`); this package does not bundle them.

```ts
import { generateIdentity, MerkleTree, computeExternalNullifier } from "@sure-circles/client";

const identity = generateIdentity();
const externalNullifier = await computeExternalNullifier(circleId, 0n);
```

The four public signals, in order, are `[nullifierHash, root, externalNullifier, recipientHash]`. See
[docs/wire-format.md](../../docs/wire-format.md).

## 5. Errors

Contract rejections surface as typed errors such as `AlreadyClaimedError` and `InvalidProofError`. See
[docs/errors.md](../../docs/errors.md) for the full list.

## 6. Amounts

Amounts are `bigint` stroops (1 XLM = 10,000,000 stroops). `xlmToStroops`, `stroopsToXlm` and `formatXlm`
convert at the edges.
